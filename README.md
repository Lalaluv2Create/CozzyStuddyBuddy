# CozzyStuddyBuddy
Cozzy Studdy Buddy is a cozy Java desktop application. Designed to help students with organizing tasks, schedules, goals, and academic planning.

## Current Features:
- User profile input
- Task creation
- Task completion tracking

## Planned Features:
- GUI interface
- User schedule input
- GPA calculator
- Study timer
- Themes
- Save/Load System
