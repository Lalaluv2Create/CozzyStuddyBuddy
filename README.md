# CozzyStuddyBuddy
Cozzy Studdy Buddy is a cozy Java desktop application. Designed to help students with organizing tasks, schedules, goals, and academic planning.

## Current Features:
- Personalized welcome screen
- Add tasks
- View all tasks
- Edit existing tasks
- Mark tasks as completed
- Delete tasks
- Assign subjects to tasks
- Set due dates
- Set task priorities (High, Medium, Low)
- Automatic save/load using text files
- Object-oriented task management
- Modular code using multiple Java classes and methods

## Planned Features:
- GUI interface
- Buddy the Mini Schnauzer mascot
  -Motivational messages from Buddy
- User schedule input
- Goal Tracking
- GPA calculator
- Study timer
- Themes
- Save/Load System

- Object-Oriented Programming (OOP)
